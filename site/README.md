# Storebase site

Marketing site for Storebase. Separate Vite app. Same chrome, type, and color as the product (`#1a1a1a`, Inter, white pills, rounded-full nav).

The drive mock on the homepage is the real Storebase UI — sidebar, search, grid/list, Settings, Terminal — wired to sample files so you can click around without a node.

## Run

```bash
cd site
npm install
npm run dev
```

Dev server is `http://127.0.0.1:43124`.
